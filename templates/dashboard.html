Set up the Google Calendar connection

  1. In the Google Cloud Console, create a project (or pick an existing one).
  2. Enable the Google Calendar API for that project (APIs & Services → Library).
  3. Create a service account (IAM & Admin → Service Accounts), then add a JSON key to it and download the file. Keep it private: anyone with it can edit the calendar.
  4. In Google Calendar, open Settings and sharing for {{ cal.calendar_id }} and share it with the service account's email address (the client_email in the JSON key, like name@project.iam.gserviceaccount.com) with the permission Make changes to events.
  5. Put the JSON key file somewhere safe on this computer and add its full path to the .env file: GOOGLE_SERVICE_ACCOUNT_FILE=/full/path/to/key.json
  6. Restart the app. This tab will then say "Configured" and appointments are copied within about a minute (or press Sync now).

Good to know

  • One-way sync. The app copies appointments into the calendar. Changes made directly in Google Calendar are not copied back, and are put back to match the app at the next sync.
  • Minimal events. Each event shows only the token, the patient's first name and last initial, and the time slot (for example "T-04 · Sunita D."). No phone number, age, reason or notes ever go to Google. A token can change when someone books or cancels earlier in the day; the titles update too.
  • Private calendar. The calendar above only shows in a browser that is signed in to a Google account with access to it; otherwise Google shows its own sign-in screen. Do not make the calendar public: it holds patient-related information.
  • Views. The embedded Google calendar offers Week, Month and Agenda only (no Day, Quarter or Year). Times are in {{ cal.timezone }}.
